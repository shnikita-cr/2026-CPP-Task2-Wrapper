# Лабораторная работа № 2 — Wrapper / Engine

Программа хранит объект, указатель на его метод и аргументы по умолчанию в классе `Wrapper`. Класс `Engine` регистрирует команду под строковым именем и при вызове передаёт в метод аргументы с учётом переопределений.

## Возможности

- Замена **целых** слов (с учётом границ слова).
- Поиск словосочетания: возвращает `Найдено` или `Не найдено`.
- Перевод первых букв каждого слова в верхний регистр.
- Перевод первой буквы предложения в верхний регистр.
- Последовательная нумерация предложений, каждое с новой строки.

Текст обрабатывается в UTF-8, в том числе русские буквы и `ё`.

## Структура проекта

- `src/Wrapper.h` — хранит объект, метод и значения аргументов по умолчанию.
- `src/Engine.h`, `src/Engine.cpp` — регистрация и выполнение команд по алиасу.
- `src/Document.h`, `src/Document.cpp` — операции с текстом.
- `src/main.cpp` — демонстрационная консольная программа.
- `src/test.cpp` — проверки работы команд и граничных случаев.
- `examples/input.txt` — исходный текст для примера.
- `CMakeLists.txt` — сборка и регистрация тестов.

## Сборка

В корневой папке проекта:

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

Для проверки строгих предупреждений GCC/Clang:

```sh
cmake -S . -B build-warnings -DCMAKE_BUILD_TYPE=Release -DCMAKE_CXX_FLAGS="-Wall -Wextra -Werror"
cmake --build build-warnings --config Release
ctest --test-dir build-warnings -C Release --output-on-failure
```

## Запуск

Для обработки `examples/input.txt`:

```sh
./build/document_app examples/input.txt result.txt
```

В Windows используйте `build\Release\document_app.exe` или путь к скомпилированному `.exe` из вашей конфигурации CMake. В интерактивном меню выбор 7 сохраняет текущий документ в указанный выходной файл, а выбор 0 закрывает программу без записи. При замене слов пустой ввод оставляет значение аргумента по умолчанию: `кот` и `пёс`.

Без аргументов программа показывает краткую справку и успешно завершается; это также позволяет запускать все исполняемые файлы в автоматических проверках без ожидания ввода.

## Пример использования архитектуры

```cpp
Document document("кот дома");
Wrapper replace(&document, &Document::replace_words,
                {{"from", "кот"}, {"to", "пёс"}});
Engine engine;
engine.register_command(&replace, "replace");
const std::string result = engine.execute("replace", {{"to", "ёж"}});
```

Здесь `from` остаётся равным `кот`, а `to` переопределяется значением `ёж`.

**Примечание:** зарегистрированный `Wrapper` и связанный объект должны существовать до завершения работы с `Engine` — класс хранит указатели, а не владеет объектами.
